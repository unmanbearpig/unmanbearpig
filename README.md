- [HostelPunk](https://hostelpunk.com/): a hostel-discovery product I built and
  run with Go, Python and PostgreSQL/PostGIS. Normalized 74M reviews from four
  sources and matched 22,600 properties across their catalogs.
  [Architecture and project notes](https://unmb.pw/blog/project/2026/05/15/hostelpunk.html).
- [Go/PostgreSQL work sample](https://gitfront.io/r/unmanbearpig/F4oiG8RsqsF3/fintual-backend-devops-go/):
  my implementation of Fintual's Backend/DevOps interview exercise, with API
  behavior tests, SQL optimization and documented benchmarks.
- [lsend](https://github.com/unmanbearpig/lsend): a scriptable LocalSend-compatible
  CLI in Rust. It adds persistent identity, JSON output, explicit receive

  describes the development process and AI assistance.
